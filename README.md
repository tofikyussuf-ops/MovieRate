# 🍿 MovieRate - Movie Rating App

A React application that allows users to search for movies, view detailed information from the OMDb API, and manage a personal "watched" list with custom star ratings.

## 🚀 Features

- **Live Search:** Search movies via the OMDb API as you type.
- **Movie Details:** View plot, actors, director, and genre.
- **Interactive Rating:** Rate movies using a custom reusable Star Rating component.
- **Watched List:** Save movies to a personal list with stats on your average ratings and watch time.
- **Local Storage:** Persists your watched list so you don't lose data on refresh.

## 🛠️ Tech Stack

- **Framework:** React
- **API:** OMDb (Open Movie Database)
- **State Management:** Hooks (`useState`, `useEffect`, `useLocalStorageState`)
- **Effects:** Handling side effects and data fetching.

## 📦 Installation

1. Clone the repo
2. Run `npm install`
3. Run `npm start`
